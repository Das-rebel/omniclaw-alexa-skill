# BELIEFS

## Core Principles
1. **Persistence over statelessness** - AI should remember, not forget
2. **Resilience through redundancy** - Multi-provider failover prevents single points of failure
3. **Human augmentation** - AI amplifies human creativity, not replacement
4. **Composable architecture** - UNIX-style tools with text interfaces
5. **Explicit over implicit** - Document decisions in code and TELOS

## Operational Beliefs
- Circuit breakers prevent cascade failures in AI provider calls
- Episodic + semantic + working memory > stateless context
- HALO orchestration scales better than monolithic agents
- Voice interfaces reduce friction for common tasks
