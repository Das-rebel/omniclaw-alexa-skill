# LEARNED

## Lessons from Production

### 2026-03
- Circuit breakers essential for multi-provider reliability
- Firestore better than in-memory for cross-session memory
- TELOS identity documentation improves agent consistency

### 2026-02
- Platform integrations break more than AI logic
- Separate error domains (AI vs platform) aids debugging
- Hook-based observability cheaper than direct instrumentation

### 2026-01
- Multi-provider routing prevents single points of failure
- HALO orchestration handles complexity better than flat agents
- Voice interfaces have higher engagement than text
