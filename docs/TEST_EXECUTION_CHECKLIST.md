## Common Issues & Solutions

### Technical Issues
**Problem**: Staging environment down
- **Solution**: Have backup date ready, reschedule session

**Problem**: Analytics not tracking
- **Solution**: Use manual timing, document issue, proceed with session

**Problem**: Recording tool fails
- **Solution**: Rely on detailed notes, document in session report

### Participant Issues
**Problem**: Participant no-show
- **Solution**: Wait 10 min, contact participant, document no-show

**Problem**: Participant wants to quit
- **Solution**: Validate feelings, offer to skip tasks, respect decision

**Problem**: Participant asks too many questions
- **Solution**: "I can't answer during tasks, but ask during debrief"

### Data Issues
**Problem**: Data collection template incomplete
- **Solution**: Complete from memory and recording, note gaps

**Problem**: Recording corrupted
- **Solution**: Rely on notes, document in report, note data limitation
