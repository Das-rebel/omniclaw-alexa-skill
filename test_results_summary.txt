❌ WEAKNESSES:
  • Keyword collision causes 42.9% routing failures
  • Generic keywords ("search", "play", "music") misroute
  • Simple keyword matching insufficient for complex queries
  • No intent refinement after initial routing

🔧 ROOT CAUSE:
  Smart router uses simple substring matching without priority weighting.
  "Search YouTube" matches "search" → WikipediaIntent instead of YouTubeIntent.

💡 SOLUTION:
  1. Implement priority-weighted scoring (service-specific phrases = higher score)
  2. Add multi-word phrase matching (e.g., "pause spotify" vs just "pause")
  3. Post-processing refinement pass for common collision patterns
  4. Expected improvement: 57% → 90%+ routing success
